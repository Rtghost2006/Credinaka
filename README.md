# Credinaka
Credinaka — Application Android de scan des cartes de recharge Orange, Yas et Airtel à Madagascar. Scannez une carte avec la caméra ou depuis une photo, puis lancez automatiquement l'appel de recharge. Essai gratuit de 2 jours et activation par téléphone.

## Télécharger

👉 **[Télécharger Credinaka (APK)](https://github.com/Rtghost2006/credinaka/releases/latest/download/credinaka.apk)**

Compatible avec Android 7.0 et plus.

## Installer

1. Touchez le lien de téléchargement ci-dessus.
2. Ouvrez le fichier `credinaka.apk` une fois téléchargé.
3. Si le téléphone le demande, autorisez l'installation depuis cette source (Chrome ou Fichiers), puis revenez en arrière et touchez **Installer**.
4. Ouvrez Credinaka et acceptez les autorisations Caméra et Téléphone.

## Comment ça marche

1. Pointez la caméra vers le code de la carte, ou choisissez une photo dans la galerie.
2. Credinaka reconnaît l'opérateur et lit le code deux fois pour éviter les erreurs.
3. L'appel de recharge démarre tout seul, puis l'appli se ferme.

| Opérateur | Code |
|---|---|
| Orange | 14 chiffres |
| Yas | 14 chiffres |
| Airtel | 15 chiffres |

## Essai gratuit et activation

- **2 jours d'essai gratuit** pour chaque téléphone, à partir du moment où vous touchez « Commencer l'essai gratuit ».
- Ensuite, une **activation payante** est nécessaire pour continuer. Prix : _à compléter_.
- Pour activer : contactez-nous sur WhatsApp au **+261 38 74 96 466** en envoyant l'**ID** affiché sur l'écran d'activation de l'appli (bouton « Copier l'ID »).
- L'activation est liée à votre téléphone : elle reste valable même si vous réinstallez l'appli.

## Autorisations

- **Caméra** : pour scanner le code de la carte.
- **Téléphone** : pour lancer l'appel de recharge.
- **Internet** : pour vérifier l'essai et l'activation de votre téléphone.

## Vie privée

Credinaka utilise l'identifiant du téléphone pour gérer l'essai et l'activation. L'appli ne conserve ni vos codes de recharge, ni vos photos, ni vos contacts. Le code est lu directement sur votre téléphone : aucune photo n'est envoyée.
